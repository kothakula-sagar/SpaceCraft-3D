# SpaceCraft 3D Planner

Advanced browser-based 3D interior planner built from the supplied Office Planner 3D prototype.

## Run
Open `index.html` in a modern browser.

The app uses Three.js from CDN, so an internet connection is needed when opening the page.

## Main features
- Office, Home, Kitchen, Bedroom, Living Room, Meeting Room, Retail and Restaurant spaces
- Adjustable room length and width
- 3D orbit, top and front views
- Furniture/object library with categories and search
- Drag-and-drop style object placement
- Grid and optional snapping
- Light interface
- Empty room on startup until objects are added
- Cursor-centered zoom
- Object selection with position, rotation and scale controls
- Duplicate, rotate, center and delete
- Undo / redo with Ctrl/Cmd+Z and Ctrl/Cmd+Y
- Save/load project JSON
- Material colors and ready-made themes
- Wall/grid visibility controls
- Responsive desktop/tablet/mobile layout
- Sample layouts for different room types
